# Void Client

**The best client - made by bisteck**

Utility client for **Minecraft Java Edition 1.21.11** (Fabric).

## Features

- Modular system (Combat, Movement, Render, Utility, HUD, Misc)
- ClickGUI dark / black & white compact
- Typed settings + JSON config
- Event bus
- Customizable HUD

## Build

```bash
./gradlew build
```

Jar: `build/libs/void-client-1.0.0.jar`

```bash
./gradlew runClient
```
